# 🏠 rentkar.in – India's Peer-to-Peer Rental Marketplace

**Rent anything, anytime** – cameras, bikes, furniture, tools & more from trusted people near you.

A modern, mobile-first rental marketplace built with pure HTML/CSS/JS + Firebase.

---

## ✨ Features

- 🔍 **Smart Search** – Location-based + keyword search
- 📂 **Categories** – Electronics, Vehicles, Furniture, Tools, Fashion & more
- ❤️ **Wishlist** – Save items you like
- 📱 **Fully Responsive** – Beautiful on mobile + desktop
- 🌙 **Dark / Light Mode**
- 🔐 **Authentication** (Email, Google, Facebook)
- 📤 **List Your Item** – Upload photos
- 📞 **Contact Owner** – WhatsApp + Phone
- 🖼️ **Lightbox** image viewer

---

## 🛠️ Tech Stack

- HTML5 + CSS3 + Vanilla JavaScript
- Firebase Authentication + Firestore
- Cloudinary (image upload)
- Font Awesome 6
- Plus Jakarta Sans font
